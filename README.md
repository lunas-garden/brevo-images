# brevo-images

Zentrale Bild-Ablage für alle Brevo-Newsletter (Transcending Women / Studio Lila / Tanja & Marcel).

## Nutzung

Bilder in `images/` ablegen, dann die Raw-URL in Brevo einbetten:

```html
<img src="https://raw.githubusercontent.com/lunas-garden/brevo-images/main/images/DATEINAME.jpg" alt="Beschreibung" width="600">
```

## Konventionen

- Dateinamen klein, ohne Leerzeichen und Umlaute, z. B. `2026-11-workshop-titel.jpg`
- Newsletter-Breite 600 px, JPG oder PNG, möglichst unter 300 KB
